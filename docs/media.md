## Rebuild derived assets

Run from the repository root. Use `uv` for Python scripts. The depth script needs an isolated Python environment with PyTorch, Transformers, NumPy, and Pillow, plus a local [Depth Anything V2 Small checkpoint](https://huggingface.co/depth-anything/Depth-Anything-V2-Small-hf). Use the final photo crop to keep the depth image aligned.

```sh
uv run --no-project --python /path/to/python python scripts/assets/build-window-depth.py --model /path/to/model public/media/panoramas/shanghai-day.webp
uv run --no-project --with fonttools --with brotli scripts/assets/build-han-font.py SourceHanSansSC-VF.ttf public/fonts/studio-han.woff2
uv run --no-project --with fonttools --with brotli scripts/assets/build-han-font.py LXGWWenKaiTC-Regular.ttf public/fonts/studio-script.woff2 "Studio Script" src/content/travel.ts
node scripts/assets/build-travel-map.mjs countries-chn.geojson maritime-chn.geojson blank-paper.jpg atlas.png
```

The atlas script writes a PNG. Convert it to WebP for `public/media/graphics/world-atlas.webp`. Update pins and captions in `src/content/travel.ts`. Window projection and lighting live in `src/scene/exterior.ts` and `src/scene/window-depth.ts`.
