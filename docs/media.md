Run these commands from the repository root to update the site fonts and the world atlas.

```sh
uv run --no-project --with fonttools --with brotli scripts/assets/build-han-font.py SourceHanSansSC-VF.ttf public/fonts/studio-han.woff2
uv run --no-project --with fonttools --with brotli scripts/assets/build-han-font.py LXGWWenKaiTC-Regular.ttf public/fonts/studio-script.woff2 "Studio Script" src/content/travel.ts
node scripts/assets/build-travel-map.mjs countries-chn.geojson maritime-chn.geojson blank-paper.jpg atlas.png
```

The atlas script writes a PNG. Export the full plate to `public/media/graphics/world-atlas.webp` and a 960-pixel-wide copy to `world-atlas-room.webp` in the same directory. The room displays the smaller plate while the full map loads. Update pins and captions in `src/content/travel.ts`. Window projection and lighting live in `src/scene/exterior.ts` and `src/scene/window-depth.ts`.
