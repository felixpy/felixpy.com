# Code of Conduct

This policy applies to participation in Felix Studio’s GitHub issues, pull requests, reviews, and other project discussions.

## Working together

- Welcome people with different backgrounds, languages, and levels of experience.
- Keep feedback specific to the work. Explain disagreements without attacking the person.
- Respect privacy. Ask before sharing someone else’s personal information or private messages.

Harassment, threats, discriminatory remarks, unwanted sexual attention, impersonation, and deliberate disruption are unacceptable in project spaces.

## Reporting and moderation

Use GitHub’s **Report content** option on the issue, pull request, or comment involved. Choose **Report to repository admins** if it is available, or use GitHub Support’s reporting option. Include links and enough context to understand what happened. Keep sensitive details out of public issues. See [GitHub’s reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Maintainers may remove content, limit participation, or block accounts based on the severity or repetition of the behavior. They should limit access to report details to the people needed to address the incident.
